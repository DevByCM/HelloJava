# AI-Powered Football Betting Intelligence Platform

An enterprise-grade platform for automated football match analysis and betting ticket generation.

## Features
- **AI Prediction Engine**: Uses ML to predict match outcomes and market probabilities.
- **Automated Bet Slips**: Generates optimized tickets with target odds.
- **SaaS Ecosystem**: JWT-based auth with Free, Registered, and Premium tiers.
- **Real-time Data**: ETL pipelines for global football data.
- **Risk Management**: Confidence scoring and filtering.

## Tech Stack
- **Backend**: FastAPI, PostgreSQL, Redis, Celery, SQLAlchemy.
- **ML**: scikit-learn, pandas, NumPy.
- **Frontend**: React, Tailwind CSS.
- **Infrastructure**: Docker, Nginx.
